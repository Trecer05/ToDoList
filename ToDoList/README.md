# ToDoList

Тестовое iOS-приложение для управления задачами.

## Возможности

- загрузка 30 стартовых задач из `https://dummyjson.com/todos`;
- сохранение данных в Core Data;
- создание и редактирование задач;
- изменение статуса выполнения;
- поиск по названию и описанию;
- удаление с подтверждением;
- системный Share Sheet;
- контекстное меню по долгому нажатию;
- работа с уже сохранёнными задачами без сети;
- обработка сетевых ошибок с возможностью повторить импорт.

## Архитектура

### TaskList

- **View** — отображает список, поиск, нижнюю панель и контекстное меню.
- **Presenter** — преобразует `TaskItem` в view model и обрабатывает действия пользователя.
- **Interactor** — запускает импорт и операции репозитория.
- **Router** — открывает редактор, Share Sheet и подтверждение удаления.
- **Entity** — `TaskItem`.

### TaskEditor

- один модуль используется в двух режимах: `.create` и `.edit(TaskItem)`;
- при нажатии «Назад» новая или изменённая задача сохраняется;
- пустая новая задача закрывается без создания записи;
- пустое название и превышение лимитов блокируются.

### Данные

`CoreDataTaskRepository` реализует `TaskRepository`. Каждая операция выполняется:

1. на последовательной `OperationQueue`;
2. в отдельном `newBackgroundContext()`;
3. с возвратом результата на `MainActor`.

Последовательная очередь исключает конфликтующие одновременные записи. Статус выполнения сохраняется как конкретное значение, а не через слепой `toggle()`, поэтому быстрые повторные нажатия не рассинхронизируют UI и Core Data.

## Первый запуск

`InitialTaskLoader` проверяет флаг успешного импорта:

- если импорт ещё не выполнялся — загружает задачи из API и сохраняет их в Core Data;
- если импорт уже завершён — сеть не вызывается;
- если сети нет — локальная часть приложения продолжает работать, а импорт можно повторить;
- `remoteID` защищает импортированные задачи от дублей.

## Запуск

1. Открыть проект в актуальной версии Xcode.
2. Выбрать схему `ToDoList`.
3. Выбрать iPhone Simulator.
4. Запустить через `⌘R`.

Приложение не требует API-ключей или сторонних зависимостей.

## Тесты

Запуск: `Product → Test` или `⌘U`.

Покрыты:

- CRUD-операции Core Data;
- валидация пустого названия;
- поиск по названию и описанию;
- идемпотентное сохранение статуса;
- однократный стартовый импорт;
- повтор импорта после сетевой ошибки;
- логика редактора;
- переход к редактированию, шаринг и подтверждение удаления.

## Основные защитные механизмы

- ограничение названия до 200 символов;
- ограничение описания до 4000 символов;
- ограничение поисковой строки;
- проверка HTTP-кода, пустого и слишком большого ответа;
- таймаут сетевого запроса;
- защита от устаревших результатов поиска;
- защита от повторного удаления одной задачи;
- rollback Core Data при ошибке;
- автоматическая лёгкая миграция Core Data;
- безопасное отображение Share Sheet на iPhone и iPad;
- привязка редактора к `keyboardLayoutGuide`;
- предупреждения пользователю вместо аварийного завершения приложения.
